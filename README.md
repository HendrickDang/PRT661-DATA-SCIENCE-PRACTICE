
📌 Overview
This repository contains our practical work for PRT565 Data Science Practice, including exploratory analysis, modelling, evaluation, and reflections. The project follows a standard data‑science workflow and demonstrates applied skills in Python, statistical modelling, and machine‑learning techniques.
